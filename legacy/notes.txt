name: Deploy to Google App Engine

on:
  push:
    branches:
      - main

jobs:
  deploy:
    name: Build and Deploy
    runs-on: ubuntu-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - id: 'auth'
        uses: 'google-github-actions/auth@v2'
        with:
          credentials_json: '${{ secrets.GCP_SA_KEY }}'

      - name: 'Set up Cloud SDK'
        uses: 'google-github-actions/setup-gcloud@v2'

      - name: 'Deploy to App Engine'
        uses: 'google-github-actions/deploy-appengine@v2'
        with:
          project_id: ${{ secrets.GCP_PROJECT_ID }}
          deliverables: |
            app.yaml
            admin/app.yaml
            webapp/app.yaml
          flags: '--no-stop-previous-version'

1. Preparación en Google Cloud (GCP)
Antes de tocar GitHub, necesitas dar permisos para que GitHub pueda "entrar" a tu cuenta de Google Cloud.

Crear una Cuenta de Servicio:

Ve a IAM y administración > Cuentas de servicio.

Crea una llamada github-deploy-sa.

Asignar Roles: Dale los siguientes permisos:

Administrador de App Engine (App Engine Admin)

Usuario de cuenta de servicio (Service Account User)

Administrador de Storage (Storage Admin)

Editor de Cloud Build (Cloud Build Editor)

Crear e ir a Claves:

Dentro de la cuenta de servicio, ve a la pestaña Claves > Agregar clave > Crear clave nueva (JSON).

Descarga el archivo. Lo usaremos en el siguiente paso.

2. Configurar GitHub Secrets
Para no exponer tus credenciales, guárdalas en tu repositorio de GitHub:

Ve a tu repo en GitHub > Settings > Secrets and variables > Actions.

Crea un New repository secret llamado:

GCP_SA_KEY: Pega aquí todo el contenido del archivo JSON que descargaste.

GCP_PROJECT_ID: El ID de tu proyecto en Google Cloud (ej: myngly-336422).

4. Crear el Workflow de GitHub Actions
Crea un archivo en tu repo en la ruta: .github/workflows/deploy.yml
