# 2026-06-24

## Slice 4 — Migrate admin + webapp SPAs to the new Myngly.Ads API (POST + JWT)

**Scope / goal.** Adapt both SPAs to the rewritten backend: JWT bearer auth (no
cookies/CSRF), POST-only JSON-RPC action endpoints under
`/api/v1/ads-{admin,advertiser}`, and a real banner upload. Apps stay fully
independent (duplicated client, no shared module).

**Changes — admin** (commit `628e438`):
- `src/api/client.ts` rewritten: JWT/POST client, `API_BASE = ${VITE_API_URL||localhost:3000}/api/v1/ads-admin`, `localStorage` tokens (`ads_admin_*`), 401→refresh-retry, RFC-7807 error parsing. Dropped CSRF/cookies.
- `AuthContext` hydrates from token + `auth/profile`; 2FA (`requiresTwoFactor`) removed end-to-end (deferred). Login page + CSS cleaned.
- Every `src/api/*.ts` rewritten to POST action endpoints (auth, users, campaigns,
  settings, dashboard, payments, email); `pagination.ts` updated to `{ data, pagination }`.
  `ApiError` moved to `src/types`.

**Changes — webapp** (commit `6d42895`):
- `src/api/client.ts` rewritten: JWT/POST + `postForm` (banner) + `postBlob` (CSV export)
  + `mediaUrl`. `API_BASE = ${VITE_API_URL||localhost:3000/api}/v1/ads-advertiser`,
  tokens `ads_advertiser_*`. Dropped CSRF/cookies/`setClientAuthenticated`.
- `AuthContext` hydrates from token; login/register store tokens; logout clears.
- Every `src/api/*.ts` rewritten (auth, user, users, events, campaigns, payments, email).
  CSV export → `postBlob('/campaigns/export')`. `getInvoice(id)` falls back to
  `invoices/list` + find-by-id (no single-get endpoint yet — backend follow-up).
- **Real banner upload:** `campaignsApi.uploadBanner(file)` → multipart `campaigns/banner`
  (field `file`) → `{ url }`. CreateAd uploads on select (with "Uploading…" state + 5 MB
  guard), persists the `url` as `bannerImage`; EditCampaign uploads on save; banners render
  via `apiClient.mediaUrl(...)`.

**Verification.**
- admin: `npm run build` 0 errors; `npm run lint` identical to baseline (6 pre-existing
  scaffolding errors, **0 new**).
- webapp: `npm run build` 0 errors; `npm run lint` byte-identical to baseline (11 errors /
  7 warnings pre-existing, **0 new**); `npm run test:run` **206 passed** (unchanged).

**Key decisions.** Tokens in `localStorage` (pragmatic Phase-1; refresh rotation revokes the
old token server-side). Media served anonymously (banner `<img src>` can't send a bearer).

**Open follow-ups.**
- **ConversionTracking page (webapp) is non-functional:** it references
  `/tracking/pixel/{campaignId}` + posts `/tracking/conversion`, which have no endpoint in
  the new API. The new model records events per-served-ad on the **mobile** surface
  (`/api/v1/ads-mobile/{impression,click,conversion}`, API-key). A proper fix needs a
  public campaign-level tracking pixel + a gateway API-key exemption for it, then re-point
  the page. Spawned as a separate task.
- Pre-existing lint errors in both apps (scaffolding/`react-refresh`) predate this work —
  clean up separately.
- Backend follow-up: add `stripe/invoices/get` so the webapp doesn't list-and-find.
